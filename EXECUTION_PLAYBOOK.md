## Contingency Plans

### If Email Open Rate is Low (<25%)
- [ ] Check deliverability (might be landing in spam)
- [ ] A/B test different subject lines
- [ ] A/B test different send times
- [ ] Review audience quality (might need to re-score)

---

### If Reply Rate is Low (<2%)
- [ ] Review email copy (might be weak value prop)
- [ ] Check if personalizations are working
- [ ] A/B test different sequences
- [ ] Review audience fit (might have wrong ICP)

---

### If Meetings Aren't Converting to Deals
- [ ] Review sales team's discovery call skills
- [ ] Create better objection handlers
- [ ] Revise proposal quality
- [ ] Check if wrong ICP (leads aren't qualified enough)

---

### If LinkedIn Engagement is Low
- [ ] Post at different times
- [ ] Try different content types
- [ ] Increase engagement on others' posts
- [ ] Check if headline/profile needs updating

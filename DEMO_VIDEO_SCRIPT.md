## 🎥 Recording Instructions

### Using Loom (Easiest):

1. **Setup** (2 min):
   - Go to loom.com
   - Start recording
   - Select screen/window to record
   - Adjust audio/camera settings

2. **Record** (5 min):
   - Follow the script above
   - Speak clearly and slowly
   - Pause between sections
   - Don't rush

3. **Edit** (2 min):
   - Trim intro/outro
   - Add title: "JARVIS PRIME Demo"
   - Add subtitle: "AI Sales Automation"
   - Share and get embed link

4. **Export**:
   - Copy embed URL
   - Replace in your code

### Using OBS (More Professional):

1. **Setup**:
   - Download OBS Studio
   - Set resolution: 1920x1080
   - Add scenes for each slide

2. **Record**:
   - Press Record
   - Follow script
   - Click through visuals
   - Stop recording

3. **Export**:
   - Export as MP4
   - Upload to YouTube
   - Get video ID
   - Replace in code

## 🎨 Visual Design Tips

### What Makes a Good Demo Video:

✅ **Clean Background** - Minimal distractions  
✅ **Large Text** - Easy to read on small screens  
✅ **Consistent Colors** - Use your brand colors (cyan, purple)  
✅ **Smooth Transitions** - No jump cuts  
✅ **Professional Audio** - Clear, no background noise  
✅ **Pacing** - Not too fast, not too slow  
✅ **Graphics** - Add simple charts/icons  

### What to AVOID:

❌ Shaky mouse movements  
❌ Too much clicking around  
❌ Real customer names/data (if confidential)  
❌ Sensitive information  
❌ Poor audio quality  
❌ Too many different applications

## ✨ Pro Tips for Recording

1. **Practice first** - Read through script 2-3 times
2. **Speak slowly** - 1/3 slower than normal conversation
3. **Pause for emphasis** - Makes it more engaging
4. **Make eye contact** - If doing voiceover, imagine talking to someone
5. **Use examples** - Specific numbers are more compelling than general statements
6. **Keep zoomed in** - Make text/graphics bigger so they're readable
7. **Minimize clicks** - Pre-open windows and navigate smoothly
8. **Use cursor focus** - Highlight important elements
9. **Add B-roll** - Show system in action, not just static screens
10. **Music** - Add subtle background music (royalty-free from YouTube Audio Library)

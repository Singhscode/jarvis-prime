### COMPONENT 4: OUTREACH SCRIPTS

**3 Core Sequences:**

```
SEQUENCE 1: "We Help Agencies Scale"
- Best for: Agencies, ₹5L-50L revenue
- Performance: 4.2% reply rate
- Use: 40% of sends

SEQUENCE 2: "Noticed You're Looking to Scale"
- Best for: SaaS founders, ₹1L-100L revenue
- Performance: 3.8% reply rate
- Use: 35% of sends

SEQUENCE 3: "We Work With [Specific Type]"
- Best for: C-suite, targeted approach
- Performance: 3.5% reply rate
- Use: 25% of sends
```

**Email Structure (4-email sequence):**
1. **Day 1:** Initial outreach (specific fact, value prop, CTA)
2. **Day 3:** Follow-up #1 (social proof, similar company, CTA)
3. **Day 5:** Follow-up #2 (urgency, scarcity, CTA)
4. **Day 7:** Final touch (soft re-engagement)

**LinkedIn Messaging Sequence (4 touchpoints):**
1. **Day 1:** Connection + message (specific fact)
2. **Day 3:** Comment on their post (value + question)
3. **Day 5:** Message with resource (helpful)
4. **Day 7:** Follow-up message (soft ask)

**Discovery Call Script:**
- Opening: Rapport + permission (2 min)
- Discovery: Listen 70%, talk 30% (8 min)
- Pitch: Solution + case study (5 min)
- Close: Get commitment or handle objection (3 min)
- Confirm: Next steps (2 min)

**Objection Handlers:**
- "We're doing outbound already" → Show the difference
- "We'd rather hire an SDR" → Show the economics
- "This sounds too good to be true" → Offer guarantee
- "How are you different?" → Feature comparison
- "We don't have a clear ICP" → Offer workshop

## TROUBLESHOOTING

### Problem: Low email open rate (<20%)
→ Check: Deliverability, spam folder, subject lines  
→ Fix: A/B test different subject lines, change send time, improve list quality

### Problem: Low reply rate (<1%)
→ Check: Email copy, personalization, audience fit  
→ Fix: Test different sequences, improve ICP scoring, review prospects

### Problem: Low meeting-to-close rate (<15%)
→ Check: Sales call quality, proposal quality, offer clarity  
→ Fix: Improve discovery call script, better objection handling, clearer pricing

### Problem: Low LinkedIn engagement (<2%)
→ Check: Post quality, posting time, audience relevance  
→ Fix: Test different content, post at different times, engage more first

### Problem: Can't book meetings
→ Check: Calendar link working, email reaching inbox, reply rate  
→ Fix: Test email deliverability, improve copy, add urgency

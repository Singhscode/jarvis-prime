PHASE 2: DAYS 8-14 (SALES SETUP)
═══════════════════════════════════════════════════════════════════════════════

SALES INFRASTRUCTURE:

□ Create sales pitch (write it out):
  □ Opening: "Hi [Name], I noticed you're a [type] agency..."
  □ Problem: "Most agencies like yours tell me..."
  □ Solution: "We solve that by..."
  □ Proof: "Here's what typically happens..."
  □ CTA: "Want to try it?"
  □ Practice saying it 10 times (out loud)

□ Create email templates (3 versions):
  □ Version A: Problem-focused ("Struggling with lead gen?")
  □ Version B: Results-focused ("Want 8-15 meetings/month?")
  □ Version C: Curiosity-focused ("Quick question...")
  □ Keep each under 200 words
  □ Include personal touch (research + mention something specific)

□ Set up Calendly:
  □ Create "Strategy Call" slot (20-30 minutes)
  □ Set availability (Mon-Fri, 9am-5pm)
  □ Time buffer: 30 min before/after calls
  □ Confirmation email: "Here's what we'll cover..."

□ Create follow-up sequences:
  □ If no response in 3 days: Resend different angle
  □ If responded (interested): Send calendar link
  □ If responded (not interested): Ask for referral
  □ Document all templates

□ Create CRM/Tracking sheet:
  □ Spreadsheet with columns:
    - Agency name
    - Founder name
    - Email
    - Date contacted
    - Response? (Yes/No)
    - Booked call? (Yes/No)
    - Demo date
    - Closed? (Yes/No)
    - Customer? (Yes/No)

TIME INVESTMENT: 4-6 hours

COMMON PITFALLS TO AVOID:

❌ Spending too much time perfecting website
  ✓ Launch at 80%. Iterate based on feedback.

❌ Writing too many LinkedIn posts
  ✓ 1-2 per week is enough. Focus on sales.

❌ Chasing wrong customers (not your niche)
  ✓ Target only marketing agencies. Say no to others.

❌ Overcomplicating the service
  ✓ Cold email → book meetings. That's it.

❌ Being too salesy on cold outreach
  ✓ Be helpful. Build relationship. Sell later.

❌ Not following up
  ✓ 80% of sales come from follow-ups.

❌ Not tracking results
  ✓ If you can't measure it, you'll lose it.

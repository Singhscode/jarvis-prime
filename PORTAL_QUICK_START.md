## 🌐 Access Portal

### From Website
1. Go to **https://jarvisprime.me**
2. Click **"Operations Portal"** button (purple/pink)
3. Done!

### Direct URLs
- Dashboard: **https://jarvisprime.me/dashboard**
- Leads: **https://jarvisprime.me/leads**
- Tasks: **https://jarvisprime.me/tasks**

## 📊 Dashboard

| Card | What It Shows |
|------|--------------|
| 📥 New Leads | Leads today |
| ✅ Qualified | Leads scoring 15+ |
| 🔥 Hot Leads | Leads scoring 20+ (CALL THESE!) |
| 📧 Emails Sent | Total emails sent |
| 📞 Calls Booked | Meetings scheduled |
| 💰 Pipeline | Total deal value |

### Agent Status
- 🟢 Running (automation working)
- ⏸ Stopped (not running)
- 🔴 Error (problem)

## 👥 Leads Manager

See all leads in a table:
- Name & Email
- Company
- Revenue tier
- **ICP Score** (0-25):
  - Red 🔴 (20+) = HOT - Call immediately!
  - Orange 🟠 (15-19) = Good - Send outreach
  - Gray ⚫ (<15) = Low - Mark lost

### Filters
All → Qualified → Contacted → Won → Lost

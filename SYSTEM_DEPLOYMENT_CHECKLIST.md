## PROBLEM SOLVING

### Email Issue: Low Open Rate (<25%)

```
Check (in order):
1. Deliverability: Are emails going to spam?
   → Test with tool like Mail-tester.com

2. Subject line: Is it compelling?
   → A/B test 3 different subjects

3. Send time: Are you sending at right time?
   → Try 8-9 AM IST instead of 1 PM

4. List quality: Is audience right?
   → Re-score prospects, remove low ICP scores

Action: Pick ONE variable, change it, re-test for 100 emails.
```

---

### Email Issue: Low Reply Rate (<1%)

```
Check (in order):
1. Email copy: Is your value prop clear?
   → Review best-performing sequences
   → Test different opening line

2. Personalization: Is it actually personalized?
   → Check that [PLACEHOLDER] replacements working
   → Add specific fact about each person

3. Audience fit: Is this the right person?
   → Re-run ICP scoring
   → Move low-score prospects to nurture track

4. CTA: Is it easy to reply?
   → Make CTA simpler: "Reply with Yes/No"
   → Add calendar link directly in email

Action: Implement ALL four changes. Re-test next 100 emails.
```

---

### LinkedIn Issue: Low Engagement (<2%)

```
Check (in order):
1. Post timing: Are you posting at peak times?
   → Try 8 AM IST (early morning)
   → Try 12 PM IST (lunch break)

2. Post content: Is it valuable?
   → Ensure: specific data, clear lesson, actionable
   → Compare engagement to your best posts

3. Post type: What performs best?
   → Case studies: 35-45% engagement
   → Industry insights: 25-35% engagement
   → Personal/behind-scenes: 15-25% engagement

4. Engagement: Are you engaging on others' posts?
   → Spend 15 min/day commenting on others
   → Reply to every comment on your posts

Action: Focus on case study posts for now. Engage 15 min daily on others' posts.
```

---

### Sales Issue: Can't Book Meetings

```
Check (in order):
1. Reply rate: Are you getting replies?
   → If not, fix emails first (see email issue above)
   → If yes, continue...

2. Calendar link: Can people actually book?
   → Test your Calendly link yourself
   → Send test email to friend, have them try booking

3. Follow-up: Are you following up on soft signals?
   → Email opens = warm lead, follow up Day 8
   → Email clicks = hot lead, follow up Day 3
   → Email reply = immediate follow-up (same day)

4. CTA clarity: Are you asking for the meeting?
   → Be explicit: "Book a 20-min call here: [link]"
   → Not subtle: "Happy to chat if relevant"

Action: Ensure calendar link works. Improve follow-up on opens/clicks. Be explicit with CTA.
```

---

### Sales Issue: Can't Close Deals

```
Check (in order):
1. Sales call quality: Are you listening?
   → Listen 70%, talk 30%
   → Understand their situation first
   → Then pitch solution

2. Proposal quality: Is it professional?
   → Include specific situation + results
   → Show numbers (ROI, new MRR, payback period)
   → Include social proof + testimonial

3. Objection handling: Are you handling pushback?
   → Have ready answers for top 5 objections
   → Use: "Fair point. Here's why this is still relevant: ___"

4. Follow-up: Are you following up?
   → Follow up within 24 hours if no response
   → Follow up every 2-3 days until decision
   → Always provide new info/value in follow-up

Action: Improve discovery call script. Better proposals. Better follow-up.
```

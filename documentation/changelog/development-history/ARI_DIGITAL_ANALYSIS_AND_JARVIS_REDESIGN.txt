PART 2: HOW ARI DIGITAL OPERATES (EXECUTION MODEL)
================================================================================

CUSTOMER JOURNEY:

STEP 1: DISCOVERY CALL (Free)
  • Prospect books Calendly call
  • Asmita or team qualifies them
  • Gathers: ICP, sales motion, messaging angles
  • Determines which plan fits

STEP 2: ONBOARDING (1-2 weeks)
  • Prospect fills "onboarding questionnaire"
  • Ari Digital comes back with:
    - Outreach angles
    - Intent signals
    - Front-end offers
    - ICP cuts
    - Strategy recommendations

STEP 3: SYSTEM SETUP (2-4 weeks)
  • Set up email infrastructure (if cold email)
  • Build prospect lists (intent-filtered)
  • Create sequences (tested templates)
  • Setup warm-up (for deliverability)
  • Setup LinkedIn (if LinkedIn outreach)

STEP 4: EXECUTION (Ongoing)
  • Run campaigns (done-for-you)
  • Track intent signals (10+ signals)
  • A/B test sequences
  • Monitor engagement
  • Nurture non-responsive prospects

STEP 5: CLOSING (Real-time)
  • When prospect engages → warm calling
  • Call script built by Ari Digital
  • Prospect notified in real-time
  • Hand off to client for actual call

STEP 6: FOLLOW-UP (Continuous)
  • Track every interaction
  • Adjust strategy based on data
  • Weekly testing & iteration
  • Monthly reporting

KEY INSIGHT: This is a HYBRID model - part software, part agency services.
They charge for the SERVICE of running outbound, not just the software.

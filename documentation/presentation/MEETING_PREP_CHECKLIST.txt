TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════════

System Won't Start:
  Problem: npm run server fails
  Fix: Verify Node.js installed, npm install ran
  Backup: Show code instead of live demo

WiFi Down:
  Problem: Internet connection lost
  Fix: Use mobile hotspot
  Backup: Use USB tethering

Laptop Issues:
  Problem: Laptop crashes or slow
  Fix: Restart 15 min before meeting
  Backup: Have backup laptop ready

Demo Fails:
  Problem: Live demo shows error
  Fix: Skip demo, show screenshot instead
  Backup: Walk through code line-by-line

Time Running Out:
  Problem: Running behind schedule
  Fix: Skip algorithm details
  Backup: Move Q&A to async (email/Slack)

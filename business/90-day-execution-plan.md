# JARVIS PRIME — 90-Day Execution Plan

## PHASE 1: Foundation (Days 1–14)
**Goal: First paying client. ₹15,000+ in bank.**

### Week 1
- [ ] Deploy brand site to Vercel (jarvis-prime.in or similar)
- [ ] Set up Cal.com booking page
- [ ] Create LinkedIn company page for JARVIS PRIME
- [ ] Optimize personal LinkedIn profile (Founder @ JARVIS PRIME)
- [ ] Build seed lead list: 200 agency founders (Apollo free + LinkedIn manual)
- [ ] Set up Resend account + warm sending domain
- [ ] Set up n8n locally (Docker)
- [ ] Load outreach templates into n8n

### Week 2
- [ ] Start sending 30 cold emails/day to seed list
- [ ] Send 10 LinkedIn connection requests/day
- [ ] Post 3 LinkedIn posts (value-first: "How we booked 18 calls for an agency in 30 days")
- [ ] DM 10 founders/day on LinkedIn after connecting
- [ ] Set up Notion CRM: columns = Lead, Status, Last Contact, Next Step, Value
- [ ] Target: 2+ discovery calls booked
- [ ] Offer 2 FREE pilots in exchange for testimonial

**Week 2 KPI targets:**
- Emails sent: 150+
- Reply rate: 5%+ = 7+ replies
- Calls booked: 2–3
- Deals closed: 1 (free pilot → paid)

## Non-Negotiable Rules

1. **Ship daily** — something live every single day
2. **Talk to 5 prospects every day** — email, LinkedIn, WhatsApp
3. **No perfection paralysis** — good enough and live > perfect and delayed
4. **Raise price every 3 clients** — Starter starts at ₹15K, Growth starts at ₹35K
5. **Document everything** — every client result is a future case study

PART 4: WORKFLOWS & AUTOMATION (n8n)
═════════════════════════════════════════════════════════════════════════════════

What is n8n?
────────────
Open-source workflow automation platform. Like Zapier, but self-hosted.
Connects different services with visual workflows.

5 Key Workflows for JARVIS PRIME

WORKFLOW 1: Daily Outreach Automation
────────────────────────────────────
Trigger: Every day at 9 AM

Flow:
  1. Get prospects due for outreach (stage="queued")
  2. For each prospect:
     a. Generate AI-personalized email
     b. Send via Resend API
     c. Update database
     d. Set next follow-up (3 days)
  3. Send Slack notification ("Sent 45 emails")

WORKFLOW 2: Reply Processing
────────────────────────────
Trigger: When email reply arrives (webhook from Resend)

Flow:
  1. Parse incoming email
  2. Find matching prospect
  3. Classify reply intent (INTERESTED, NOT_INTERESTED, etc)
  4. If INTERESTED:
     - Create calendar meeting
     - Alert sales team in Slack
     - Update prospect stage to "booked"
  5. If NOT_INTERESTED:
     - Add to suppression list
     - Mark as disqualified

WORKFLOW 3: Weekly Performance Report
──────────────────────────────────────
Trigger: Every Monday at 9 AM

Flow:
  1. Calculate weekly metrics:
     - Emails sent
     - Reply rate
     - Meetings booked
     - Estimated revenue
  2. Generate PDF report
  3. Send to all clients via email
  4. Update Google Sheets dashboard

WORKFLOW 4: Lead Enrichment Pipeline
─────────────────────────────────────
Trigger: When new prospect is added

Flow:
  1. Call Apollo API → get company info
  2. Call Hunter API → get email variants
  3. Calculate ICP score
  4. If qualified (score >= 70):
     - Mark as "queued"
     - Add to next morning's outreach

WORKFLOW 5: Anomaly Detection
──────────────────────────────
Trigger: Daily at 6 PM

Flow:
  1. Check if reply rate dropped below 15%
     - If YES: Alert founder in Slack
  2. Check if daily limits approaching
     - If YES: Warn to throttle
  3. Check for email delivery failures
     - If YES: Retry failed sends

KEY ALGORITHMS
═════════════════════════════════════════════════════════════════════════════════

ALGORITHM 1: ICP Scoring
────────────────────────
Calculates how well prospect matches client's ideal customer.

Scoring:
  - Title match (CEO, Founder, etc): 30 points
  - Industry match (SaaS, B2B, etc): 30 points
  - Keywords match (scaling, growth): 20 points
  - Location match (USA, India, etc): 10 points
  - Recency bonus: 10 points
  ─────────────────────────
  Total: 0-100 points

Qualification:
  Score >= 80 → HOT (immediate outreach)
  Score 70-79 → QUALIFIED (normal outreach)
  Score < 70  → NOT QUALIFIED (save for later)

ALGORITHM 2: Email Personalization
───────────────────────────────────
AI generates unique, personalized emails for each prospect.

System:
  1. Gets prospect data (name, title, company, news)
  2. Sends to GPT-4 with prompt
  3. GPT-4 generates subject + body
  4. Subject is unique (not templated)
  5. Body references specific company details

Example:
  Generic: "Hi [Name], check out our product"
  
  Personalized: "Hi John, I saw TechCorp raised Series B. 
                 Congrats! Most Series B funded SaaS are 
                 growing 20% MoM. We help companies like 
                 you scale customer acquisition. Quick call?"

ALGORITHM 3: Reply Classification
──────────────────────────────────
Automatically determines what kind of reply we received.

Classes:
  INTERESTED        → "Yes, let's talk!" / "Sounds good"
  NOT_INTERESTED    → "No thanks" / "Not interested"
  UNSUBSCRIBE       → "Remove me" / "Stop emailing"
  BOUNCE            → Email invalid / mailbox full
  NEEDS_FOLLOWUP    → Unclear message, needs manual review

System:
  1. Check for keyword matches (fast)
  2. If unclear, send to GPT-3.5 for classification
  3. Take action based on classification

Q: How is this different from Outreach?
A: Outreach is for enterprise sales teams ($50K+/year).

Q: How do we ensure high delivery rates?
A: We use Resend (trusted email provider).
   Warm-up domain before sending.
   Monitor bounce rate closely.

Q: What's the refund policy?
A: 30-day money-back guarantee.
   No questions asked.

Q: Can we integrate with client's CRM?
A: Yes! Via n8n workflows.
   Or via our Zapier/Make integration.

Q: How do we handle GDPR/CAN-SPAM?
A: Every email includes unsubscribe link.
   Auto-suppress on unsubscribe.
   Log all actions for compliance audit.

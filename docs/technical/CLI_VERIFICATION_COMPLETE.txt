1. Database Setup (Supabase)
   cd engine && npx supabase db push
   Configure SUPABASE_URL & SUPABASE_KEY in .env

2. Enable Live Email (Resend)
   Set RESEND_API_KEY in .env
   Verify sender email is confirmed

3. Connect Apollo for Real Prospects
   Set APOLLO_API_KEY in .env
   Adjust ICP scoring filters in config.js

4. Schedule Automation (Hourly)
   Set SCHEDULER_ENABLED=true in .env
   Will run: source → score → outreach every hour

5. Connect Reply Detection
   Set up IMAP poller or Gmail webhook
   See: engine/src/agents/inbound-agent.js

6. Deploy to Production
   npm run build
   npm start

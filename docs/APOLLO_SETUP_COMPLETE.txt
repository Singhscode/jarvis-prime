SETUP REQUIRED (5 MINUTES)
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Create Apollo.io Account
   → Go to: https://app.apollo.io
   → Sign up (free plan available)
   → Verify email

STEP 2: Get API Key
   → Login → Settings → API
   → Click "Create API Key"
   → Copy the key

STEP 3: Add to Environment
   → Open: agents/.env
   → Add line: APOLLO_API_KEY=your_key_here
   → Save file

STEP 4: Test Integration
   → Run: cd agents && node --env-file=.env test-apollo.js
   → Should see: ✅ Found 5 prospects
   → Should see: ✅ Apollo.io integration is working correctly!

STEP 5: Find Your First 50 Prospects
   → Run: cd agents && node --env-file=.env src/tools/prospect-finder.js
   → Results saved to: agents/src/prospects.csv
   → Ready for outreach campaigns!

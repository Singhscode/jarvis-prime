3. SETUP INSTRUCTIONS
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Create Apollo.io Account
   1. Go to: https://app.apollo.io
   2. Sign up (free plan available)
   3. Verify your email address

STEP 2: Get API Key
   1. Log in to Apollo.io
   2. Click your profile (top right) → Settings
   3. Navigate to "API" section
   4. Click "Create API Key"
   5. Copy the API key (starts with your email)

STEP 3: Add to Environment Variables
   1. Open: agents/.env
   2. Add this line:
      APOLLO_API_KEY=your_api_key_here
   3. Save the file

STEP 4: Test Integration
   Run: cd agents && node --env-file=.env test-apollo.js

   Expected output:
   ✅ Apollo.io API key found
   ✅ Found 5 prospects
   ✅ Apollo.io integration is working correctly!

4. API FEATURES AVAILABLE
═══════════════════════════════════════════════════════════════════════════════

SEARCH FUNCTIONS:

1. searchPeople(filters, limit)
   • Find prospects by title, location, company size, industry
   • Returns: name, title, email, phone, LinkedIn, company data
   • Use for: Building prospect lists

2. searchCompanies(filters, limit)
   • Find companies by location, size, industry, tech stack
   • Returns: company data, employee count, revenue, technologies
   • Use for: Account-based marketing

3. findIndianAgencyFounders(limit)
   • Pre-configured search for JARVIS PRIME's exact ICP
   • Targets: Founders, CEOs, Marketing/Sales VPs in Indian agencies
   • Company size: 1-200 employees
   • Keywords: "digital marketing", "lead generation", "B2B SaaS"
   • Use for: Daily prospect sourcing

4. findSaaSFounders(limit)
   • Pre-configured search for B2B SaaS founders in India
   • Targets: Founders, CEOs in software/platform companies
   • Company size: 11-500 employees
   • Use for: SaaS-specific campaigns


ENRICHMENT FUNCTIONS:

5. enrichPerson(personId)
   • Enrich by Apollo ID
   • Returns: Full contact details + employment history
   • Use for: Deep research on specific prospects

6. enrichByEmail(email)
   • Enrich by email address
   • Returns: Full profile + company data + phone numbers
   • Use for: Inbound lead enrichment

7. enrichProspectList(prospects)
   • Batch enrich existing prospect list
   • Rate limited: ~50 per minute
   • Use for: Upgrading Hunter.io or manual lists

8. getOrganization(domain)
   • Get company details by domain
   • Returns: Full company profile + tech stack
   • Use for: Company research

EXAMPLE 2: Enrich Inbound Lead (in your agent code)

   import { enrichByEmail } from './lib/apollo.js';
   import { scoreICP } from './lib/icp-scorer.js';

   async function handleInboundLead(email, name, company) {
     // Enrich with Apollo.io
     const enriched = await enrichByEmail(email);
     
     // Score with enhanced ICP scorer
     const score = scoreICP(enriched);
     
     if (score.hot) {
       // Hot lead — notify founder immediately
       await sendTelegram(`🔥 HOT LEAD: ${score.score}/30\n${name} @ ${company}`);
     }
     
     return { enriched, score };
   }


EXAMPLE 3: Find Prospects Using Specific Tech Stack

   import { searchPeople } from './lib/apollo.js';

   const prospects = await searchPeople({
     person_locations: ["India"],

     organization_num_employees_ranges: ["11,50", "51,200"],

EXAMPLE 4: Custom Search with Keywords

6. ICP SCORING ENHANCEMENTS
═══════════════════════════════════════════════════════════════════════════════

UPGRADED SCORING SYSTEM (25 pts → 30 pts):

Original Scoring (25 points max):
  • Revenue tier: 0-10 pts
  • Message relevance: 0-8 pts
  • Phone provided: 2 pts
  • Detailed message: 2 pts
  • Decision maker: 3 pts

NEW Apollo.io Bonuses (adds 10 points):
  • Company size scoring: 0-10 pts
    - 1-10 employees: 8 pts (perfect fit)
    - 11-50 employees: 10 pts (sweet spot)
    - 51-200 employees: 7 pts (good fit)
    - 201-500 employees: 4 pts (possible)
  
  • Tech stack relevance: 0-3 pts
    - Uses: HubSpot, Salesforce, Intercom, Analytics tools
  
  • Company LinkedIn verified: 1 pt
  • Apollo.io verified contact: 2 pts
  • Personal LinkedIn profile: 1 pt

QUALIFICATION THRESHOLDS:
  • Qualified: Score >= 15 (send to outreach)
  • Hot Lead: Score >= 22 (founder follows up personally)
  • Perfect Fit: Score >= 28 (priority outreach, same day)

8. BEST PRACTICES
═══════════════════════════════════════════════════════════════════════════════

1. DAILY PROSPECT SOURCING:
   • Run prospect-finder.js every Monday morning
   • Generate 50-100 prospects per week
   • Filter by ICP score >= 15 before outreach
   • Prioritize hot leads (score >= 22) for same-day follow-up

2. INBOUND LEAD ENRICHMENT:
   • Enrich every inbound lead with enrichByEmail()
   • Use enriched data for better ICP scoring
   • Segment by company size and tech stack
   • Route hot leads to founder immediately

3. MULTI-CHANNEL OUTREACH:
   • Use email + LinkedIn + phone (if score >= 20)
   • Email first, LinkedIn after 2 days, phone after 5 days
   • Phone numbers = 3x higher close rates
   • Personalize using Apollo company data

4. DATA QUALITY:
   • Always verify emails before sending (use email-verifier.js)
   • Check phone numbers exist before calling
   • Update prospect data monthly (re-enrich)
   • Remove bounced emails from lists

5. CREDIT OPTIMIZATION:
   • Use search (free) before enrichment (costs credits)
   • Batch enrich only qualified prospects
   • Don't enrich low-score leads (< 10 pts)
   • Track credit usage in Apollo dashboard

6. COMPLIANCE:
   • Follow CAN-SPAM Act (include unsubscribe)
   • GDPR compliance for EU prospects
   • Don't call DND registered numbers
   • Respect opt-outs immediately

9. TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

ERROR: "APOLLO_API_KEY is required"
   FIX: Add APOLLO_API_KEY to agents/.env file

ERROR: "API key is invalid"
   FIX: Regenerate API key in Apollo.io settings

ERROR: "No prospects found"
   POSSIBLE CAUSES:
   • Filters too restrictive (widen search criteria)
   • No credits remaining (check dashboard)
   • API key expired (regenerate)

ERROR: "Rate limit exceeded"
   FIX: Wait 60 seconds, auto-handled by apollo.js

ERROR: "Insufficient credits"
   FIX: Upgrade plan or wait for monthly reset

WARNING: Low enrichment success rate (< 50%)
   CAUSES:
   • Using personal emails (use work emails)
   • Prospects outside Apollo database
   • Invalid email addresses
   FIX: Verify emails first with email-verifier.js

SLOW PERFORMANCE:
   • Rate limiting active (50 requests/min)
   • Each prospect takes ~1.2 seconds
   • 50 prospects = ~1 minute (expected)
   • Use smaller batches for faster results
